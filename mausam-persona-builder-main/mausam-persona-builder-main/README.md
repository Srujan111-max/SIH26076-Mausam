# Mausam Persona Builder

Build a polished mobile-first UI prototype for the Mausam personalized weather app based on the attached reference and supplied Flask/API behavior. Start with multi-select onboarding asking “How can Mausam help you?” using Farmer, Traveller, Commuter, Runner plus optional Family and Health; include Skip and Continue. Show conditional preference screens for Farmer, Traveller, Commuter, and Runner, then personalized role-based dashboards with realistic weather metrics, safe contextual insights, alerts, and bottom navigation. Match the visual direction of the attached reference: light blue background, crisp white cards, Indian weather app feel, blue CTA, responsive centered phone layout. Implement the experience as a smooth clickable frontend prototype with mock data aligned to the provided endpoints; do not use Flask, as this needs to run as a Lovable web app.
